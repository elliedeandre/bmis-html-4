How to Center an Image on a Web Page

Six short steps and a bonus, each with the code and a live example that moves so you can watch it work.

By default, a browser puts every image on the left side of its container. Centering it takes one small piece of CSS. Which piece depends on how you want to do it, so we will go from the simplest idea to the most powerful one. In every example below, the dashed box is the “page” and the blue rectangle is the image.

Watch the motion: in each example the image starts at the default left spot and slides into its centered position, then repeats. The sliding is only there to help you see what the centering code does. The real centering code is the short snippet shown above each example. Step 7 teaches the animation code itself.

1Start with a normal image

Here is an image in plain HTML. Nothing is centering it, so it sits against the left edge.

The HTML
<img src="photo.jpg" alt="Describe the picture" width="400">
What you see
Always write the alt text. It is read aloud for people who cannot see the image and shown if the image fails to load.

2Method A: text-align: center on the parent

An <img> is an inline element, which means it behaves like a letter in a line of text. So you can center it the same way you center text: put it inside a container and center the container's contents.

The HTML
<div class="center-me">
  <img src="photo.jpg" alt="Describe the picture">
</div>
The CSS
.center-me {
  text-align: center;
}
What you see
Common mistake: the text-align goes on the parent (the <div>), not on the <img> itself. Putting it on the image does nothing.

3Method B: display: block and margin: 0 auto

This is the most popular way, and it is the one you can put directly on the image with no wrapper. Two lines do the job. First, display: block turns the image into a block-level box. Second, margin: 0 auto says “zero space above and below, and split all the leftover space equally on the left and right.”

The CSS
img {
  display: block;
  margin: 0 auto;
}
What you see
Common mistake: leaving out display: block. Auto margins do not center an inline element, so the image stays on the left. Here is that exact mistake, with margin: 0 auto but no display: block:
This is the same approach used as an inline style on the ranking pages: style="display: block; margin: 0 auto;". A class in styles.css does the same thing without repeating it on every image (see “Put it on your own site” near the bottom).

4Method C: Flexbox

Flexbox is the modern layout tool. Turn the parent into a flex container, then tell it to center its children along the horizontal line.

The HTML
<div class="flex-center">
  <img src="photo.jpg" alt="Describe the picture">
</div>
The CSS
.flex-center {
  display: flex;
  justify-content: center;
}
What you see

justify-content controls the main (horizontal) direction. Its partner align-items controls the other (vertical) direction, which is what makes Step 6 possible.

5Method D: Grid

CSS Grid has the shortest centering code of all. One line centers the image both horizontally and vertically inside its container.

The CSS
.grid-center {
  display: grid;
  place-items: center;
}
What you see

6Center it in the middle of the whole page

So far we centered left-to-right. To center an image vertically too, the container needs a height to be centered within. Give it the full height of the browser window with 100vh (“100% of the viewport height”), then center in both directions.

The CSS
.page-center {
  display: flex;
  justify-content: center;  /* left to right */
  align-items: center;      /* top to bottom */
  min-height: 100vh;        /* as tall as the window */
}
What you see (the box is 220px tall here instead of the full window)

7Bonus: make the centered image move

CSS can animate an image with two pieces: a @keyframes block that describes the movement, and an animation line that plays it. Here the centered image floats up and down.

The CSS
.float-img {
  display: block;
  margin: 0 auto;                          /* still centered */
  animation: float 2.4s ease-in-out infinite;
}

@keyframes float {
  0%, 100% { transform: translateY(0); }   /* resting spot */
  50%      { transform: translateY(-12px); } /* halfway: 12px up */
}
What you see

What each part of the animation line means:

  1. float is the name of the @keyframes block to play.
  2. 2.4s is how long one full loop takes.
  3. ease-in-out starts and ends gently instead of moving at a constant speed.
  4. infinite repeats the loop forever. Use 1 to play it once.
Move the image with transform, as above. If you animated margin instead, you would break the margin: 0 auto that is keeping the image centered.

MethodBest forCenters

C. FlexboxSeveral items, or when you also need vertical centeringBoth
D. Grid place-itemsShortest code for one centered itemBoth

Put it on your own site

Add one reusable rule to your styles.css, then give any image that class.

In styles.css
.center-img {
  display: block;
  margin: 0 auto;
}
In any page
<img src="images.webp" alt="Sora Matsushima" width="400" class="center-img">

Now run through this checklist if an image refuses to center:

  1. Did you use display: block with margin: 0 auto?
  2. Did you put text-align: center on the parent, not the image?
  3. Is the page linked to styles.css with <link rel="stylesheet" href="styles.css">?
  4. Does the file name match exactly, including capital letters? Home.png and home.png are different files on GitHub Pages.
  5. For vertical centering, did you give the container a height (like min-height: 100vh)?
